scripts/leg_runner.py ＋95 加一个 distributed 前置：env → process group、barrier + 跨 rank 取 max、per-rank 落盘、候选预编译。仍是同一个文件被两条腿执行，所以「腿的身份只由 overlay 决定」这条不变量原样成立。
